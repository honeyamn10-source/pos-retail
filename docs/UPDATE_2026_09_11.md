# Jawa POS update — 11 September 2026

## Delivered in this update

- An interactive, explicitly labelled sample walkthrough using the real Restaurant,
  Retail and Back office components. Sample actions use the existing transaction
  engine, remain in memory and reset on navigation/reload. No merchant API calls.
- Actual browser screenshots for both registers and the kitchen.
- A missing-sign-in state with a direct sign-in action, replacing indefinite loading.
- Web Crypto UUID compatibility for local HTTP walkthroughs.
- Audited cash-in/cash-out movements included in expected drawer and closing variance.
- Restaurant/Retail/Both report selection, including correct later-return attribution.
- Updated source kits and validation evidence.

## Current status

This update does not complete the commercial release. No card provider, physical
printer or telephone account has been activated. Staff roles, scalable normalized
storage, backup restoration, Canadian tax/cash rounding, modifiers/split checks,
offline operation and other features in the commercial checklist remain unfinished.
Screenshots show the current UI with sample data, not a deployed merchant session.
