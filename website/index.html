Code you can click, data you control.

Portfolio POS systems usually contain code but nothing you can click. pos-retail is a living demonstration: a self-hosted retail register with cash sales, held carts, inventory and back-office reports — no cloud subscription, no forced login, no third-party merchant database.

Capabilities

What an honest cash register does

💵

Cash sales & returns

A SQLite transaction journal committed atomically with stock movements — money and inventory move together or not at all.

🛒

Held carts

Pause a sale and come back to it later, nothing lost while the counter gets busy.

📦

Inventory with live stock

Stock levels update automatically from each completed transaction.

👥

Staff action permissions

Per-role controls enforced server-side — not a cosmetic UI toggle.

🔍

Owner-only order history

A searchable history of every transaction, visible only to the owner.

📊

Business-date CSV reports

Custom reports aligned to your business date for day-end and back-office use.

💾

Encrypted backup & recovery

Backups include the transaction journal and restore the complete register state.

🖥️

Desktop launchers

Prebuilt-kit launchers for Windows, macOS and Linux get a register up fast.

Architecture

Next.js UI, Hono API, SQLite on your machine

Next.js 15 UI React 18 + Tailwind→ Hono API Cloudflare Workers runtime→ SQLite + Drizzle ORM transaction journal | REST + WebSocket→ 127.0.0.1:8787 loopback only→ encrypted backups
LayerResponsibility
app/Next.js App Router UI — register, cash drawer, print queue, online order, manage.
server/Hono API on the Cloudflare Workers runtime; sessions & permissions enforced here.
db/ · drizzle/SQLite schema and Drizzle ORM, migrations versioned.
integrations/Extensibility seams for payments and printing (live card payments unfinished).
docs/decisions/ADRs 0001–0003: architecture, loopback-only serving, honest transaction data.
tests/Registry API, engine, ledger, cash drawer and launcher tests.

Run it

Your server, your data, four commands

Local quick start

git clone https://github.com/honeyamn10-source/pos-retail.git
cd pos-retail
pnpm install --frozen-lockfile     # Node 20 LTS / pnpm 9+
pnpm run build:server
pnpm run start:server

Open http://localhost:8787 and use data/setup-token to create your owner account.

Security

Security posture you can verify in the repo

🪙

No default passwords

The owner account is created from a secure setup token. There is no admin/admin backdoor.

🔒

Server-side enforcement

Sessions and staff permissions are enforced on the server, not hidden in the UI layer.

🧹

Clean repository surface

No secrets, no merchant database, no node_modules and no private hosting identifiers committed.

🔗

Reproducible build assets

Large OCR assets are regenerated during build from locked packages rather than vendored blindly.
