Features

Built for retail operations that need reliability at the edge.

🛒 Cart & Checkout

Real-time cart, quantity edits, discounts, tax calculation, receipt generation (thermal + PDF).

📦 Inventory Sync

Real-time stock levels, low-stock alerts, barcode scanning, variant support (size/color).

💳 Payments

Cash, card (Stripe Terminal ready), split payments, refunds, voids, end-of-day reconciliation.

👥 Staff Management

Role-based access (cashier/manager/admin), shift tracking, PIN + biometric auth.

📊 Analytics

Sales by hour/day/week, top products, staff performance, average ticket, conversion funnel.

🔒 Security

No default passwords, setup token flow, encrypted PINs, audit log, GDPR-compliant data export.

Architecture

Edge-first. Serverless by default. SQLite for simplicity, D1 for scale.

tech stack
Frontend (Next.js 15) ├── App Router (React 19, Server Components) ├── Server Actions (mutations without API routes) ├── Tailwind CSS (design system, dark mode) ├── shadcn/ui (accessible components) ├── React Hook Form + Zod (validation) └── TanStack Query (server state) Backend (Cloudflare Workers / Hono) ├── Hono (ultra-fast router, 0 deps) ├── Drizzle ORM (type-safe SQL, migrations) ├── SQLite / D1 (embedded / distributed) ├── Better Auth (session, roles, 2FA) └── Zod (runtime validation) Infrastructure ├── Cloudflare Pages (frontend hosting) ├── Cloudflare Workers (API, edge compute) ├── Cloudflare D1 (SQLite at edge) ├── Cloudflare R2 (receipts, exports) └── Wrangler (local dev, deploy)

Controlled Pilot

pos-retail is in controlled pilot. Not open for public signup.

🎯 1,000 Order Bound

Hard limit enforced at database level. Prevents runaway costs during pilot.

🔐 No Default Passwords

First admin created via one-time setup token delivered out-of-band. No admin/admin.

📍 Loopback Only

Binds to 127.0.0.1:8787. No external exposure without explicit tunneling.

📋 ADR Trail

Three Architecture Decision Records document every major choice.

📈 Graduation Criteria

Pilot graduates when: 500+ orders processed, <0.1% error rate, 99.9% uptime over 30 days.

Architecture Decision Records

ADR-001: Cloudflare Workers over Node.js

Status: Accepted
Date: 2025-01-15
Context: Need global distribution, zero cold starts, per-request billing.
Decision: Hono on Cloudflare Workers. SQLite via D1.
Consequences: No long-running processes. Stateless by default.

ADR-002: Drizzle ORM over Prisma

Status: Accepted
Date: 2025-01-20
Context: Edge runtime compatibility, bundle size, type safety.
Decision: Drizzle. No query engine binary. Full TypeScript inference.
Consequences: Manual migrations. No Prisma Studio.

ADR-003: Controlled Pilot Model

Status: Accepted
Date: 2025-02-01
Context: Retail POS requires high reliability. Can't iterate in production.
Decision: 1000-order cap, setup tokens, loopback binding, explicit graduation criteria.
Consequences: Slower feature velocity. Higher confidence.
