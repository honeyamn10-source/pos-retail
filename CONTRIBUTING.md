# Contributing

Start with the README and current release limitations. For a substantial change, describe the problem in an issue before building it; this helps avoid duplicate or incompatible work.

## A useful contribution

1. Work on a branch and keep the change focused.
2. Follow any AGENTS.md instructions in the relevant directory.
3. Use fictional test data and keep local credentials outside Git.
4. Run the applicable checks documented by the project.
5. Update setup instructions when configuration or behavior changes.
6. Open a pull request explaining the problem, behavior change and validation.

Do not replace tests with hardcoded success, remove failing checks to make a badge green, or claim a feature is verified without evidence.

## Third-party code

Include the upstream repository, exact version or commit, license and required notices with any imported code. Preserve author attribution. Do not copy client-specific content, proprietary assets or code without permission. A repository's popularity does not establish reuse rights.

## Reporting problems

Use the bug report form with reproducible steps and the tested version. Do not post secrets, customer data or private documents. These guidelines do not promise response times or commercial support.
